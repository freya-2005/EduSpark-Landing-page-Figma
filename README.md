# EduSpark — Responsive Landing Page

## 📚 About the Project
EduSpark is a modern online learning platform landing page designed to help students, beginners, and professionals discover courses and develop new skills. The design is inspired by premium minimalist portfolio websites, featuring a dark background, elegant cream accents, bold typography, and clean layouts.

## ✨ Features
- **Home Page:** Introduction, hero section, learning statistics, and call-to-action buttons.
- **Courses Page:** Course categories, course cards, and course exploration.
- **Features Page:** Expert mentors, interactive learning, flexible access, and career certificates.
- **Watch Demo Page:** Demo video section and step-by-step learning overview.
- **Responsive Design:** Layouts designed for desktop, tablet, and mobile screens.
- **Reusable Components:** Consistent navigation, buttons, feature cards, and footer.
- **Figma Prototyping:** Interactive navigation between pages using prototype connections.

## 🎨 Design System
- **Primary Background:** `#101116`
- **Accent Color:** `#F2EBD9`
- **Primary Text:** `#FFFFFF`
- **Secondary Text:** Muted grey
- **Typography:** Inter or a similar modern sans-serif font
- **Design Style:** Minimalist, modern, and professional

## 🛠️ Tools Used
- Figma
- Auto Layout
- Reusable Components
- Prototype Interactions
- Shared Color and Typography Styles

## 🎯 Target Audience
College students, job seekers, beginners, and working professionals interested in learning new skills through online courses.

## 🚀 Getting Started
1. Open the EduSpark design file in Figma.
2. Review the Home, Courses, Features, and Watch Demo frames.
3. Use Prototype mode to connect navigation links and buttons.
4. Click Present to preview and test the interactive prototype.

## 📌 Project Objective
To design a visually appealing and responsive product landing page using Figma's Auto Layout, reusable components, consistent design styles, and prototype interactions.
